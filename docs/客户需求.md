## 一、实验整体目标

完成**Spring Boot在线教育平台**从需求分析、详细设计、建模到部分服务开发上线全流程，综合运用软件工程课程知识，掌握 UML 建模、draw.io（开源）、IDEA 等工具，把软件工程方法应用到软件生命周期各个阶段。
### 1. 需求说明书
1. 编写需求规格说明书（或者用例说明文档）
2. 使用 VISIO 手动绘制**用例图**

> 
> 参考系统功能模块：
> 
> 
> - 后台：后台登录、讲师管理、课程分类管理、课程管理
> - 前台：首页展示、前台登录注册、讲师列表 / 详情、课程列表 / 详情、课程支付

### 2. 体系结构设计

绘制在线教育平台**体系结构图**。

### 3. 详细设计

1. 数据库设计 + 构件级设计
2. 使用 IDEA 插件自动生成**类图**
3. 使用 VISIO 绘制**E‑R 图、活动图**等 UML 模型图

### 4. 服务开发上线

挑选**登录以外的 1~2 个业务服务功能**，完成编码开发并等待部署上线。

### 5. 结果分析

对全部设计文档、建立的各类模型做分析描述，整理写入实验报告。
