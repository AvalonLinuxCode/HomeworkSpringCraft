## 四、体系结构设计

### 4.1 架构风格

**分层架构（Layered Architecture）** + **前后端分离**

### 4.2 架构分层

```
┌─────────────────────────────────────────────┐
│                  客户端层                      │
│    浏览器 (前台)  │  浏览器 (后台管理)          │
├─────────────────────────────────────────────┤
│                Web 层 (Controller)            │
│    Spring MVC / REST API                     │
├─────────────────────────────────────────────┤
│                业务逻辑层 (Service)            │
│    讲师服务 · 课程服务 · 分类服务 · 支付服务    │
├─────────────────────────────────────────────┤
│                数据访问层 (DAO / Mapper)       │
│    MyBatis / Spring Data JPA                 │
├─────────────────────────────────────────────┤
│                数据存储层 (PostgreSQL)         │
└─────────────────────────────────────────────┘
```

## 八、遇到的问题与解决方案

### 8.1 数据库连接问题

**问题**：应用连接 PostgreSQL 时报「对表 instructor 的权限不足」

**原因**：DDL 以 `postgres` 超级用户身份执行，表属主是 `postgres`，应用账号 `edu_user` 无权限

**解决**：以 `edu_user` 身份重新执行 DDL

```bash
PGPASSWORD=edu_password ./psql.exe -h 127.0.0.1 -p 5433 -U edu_user -d edu_platform \
  -v ON_ERROR_STOP=1 -f "docs/Design_Description/schema.sql"
```

### 8.2 Maven 环境问题

**问题**：Windows Git Bash 中 `mvn` 命令挂起

**原因**：Maven 的 `find_maven_basedir` 脚本在 msys 环境下无限循环

**解决**：设置 `MAVEN_BASEDIR` 环境变量或使用 `mvn.cmd` 从 cmd.exe 执行

### 8.3 时间戳更新问题

**问题**：`updated_at` 字段未自动更新

**原因**：MyBatis-Plus 默认策略与数据库触发器冲突

**解决**：实体类中时间戳列配置 `insertStrategy = NEVER, updateStrategy = NEVER`，交由数据库触发器维护
