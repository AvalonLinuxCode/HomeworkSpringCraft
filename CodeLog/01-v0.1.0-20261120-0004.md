## 关键决策

1. **MyBatis-Plus，不是 JPA**。设计文档中 `entity/`(JPA) 与 `mapper/`(MyBatis) 并存属文档残留；Mapper 接口 + XML 才是构件级设计的契约。`entity/` 只是可变 POJO。
2. **不用 Lombok**。JDK 25 上注解处理器版本匹配是纯风险，收益仅为省 getter。ORM 实体用可变 POJO，DTO/VO/PageResult 用 record——只有一套约定。
3. **DDL 只有一份**。`docs/Design_Description/schema.sql` 是唯一事实来源，构建期复制到测试类路径，模块内不建副本。
4. **DDL 整段执行**。`schema.sql` 含 `$$ ... $$` 的 plpgsql 函数体，Spring 的分号切分器会切碎它，故集成测试用 `Statement.execute(整段)` 走 PostgreSQL 简单查询协议。
5. **不建 `CourseMapper`**。删除校验的 `countCoursesByInstructorId` 挂在 `InstructorMapper`（讲师是课程的聚合根），省掉只有一条 SQL 的 Mapper 和半截 `Course` 实体。
6. **集成测试不用 Testcontainers**。本机 Docker 守护进程未运行；改用 zonky embedded PostgreSQL 16，`mvn verify` 不依赖 Docker。
7. **删除校验是双保险**。`course.instructor_id` 已有 `ON DELETE RESTRICT` 兜底，Service 层校验的作用是让调用方拿到 400 而不是 500。
